## 📖 About This Repository

This repository documents my journey of learning **Python for DevOps** through practical notes, code examples, and automation projects.

Instead of learning Python syntax alone, the goal is to understand how Python can help automate repetitive tasks, process files, work with APIs, manage AWS resources, and build useful tools for DevOps workflows.

The notes use simple explanations and examples to make concepts easier to understand and practice.

### 🎯 What You Will Learn

- Python fundamentals, data types, and operators
- Functions, modules, packages, and virtual environments
- Conditional statements and loops
- Lists, tuples, dictionaries, and sets
- File handling and directory automation
- Command-line arguments and environment variables
- REST API integration and JSON processing
- AWS automation using Boto3
- Building APIs and webhook integrations using Flask
- Connecting GitHub issues with Jira through Python

## 🛠️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Maniraj-CS/python-for-devops.git
cd python-for-devops
```

### 2. Check Your Python Version

```bash
python3 --version
```

### 3. Start Learning

Open the `notes/` directory and begin with `ch_1.md`.

```text
python-for-devops/
├── notes/
│   ├── ch_1.md
│   ├── ch_2.md
│   ├── ch_3.md
│   ├── ...
│   └── ch_13.md
└── README.md
```

Follow the examples, run the code on your machine, modify it, and try the practice tasks yourself.

> **Tip:** Use a Python virtual environment when installing project dependencies. For AWS exercises, configure credentials securely and use only the IAM permissions the task requires.

## 🎯 Learning Approach

1. **Read** the concept and understand the example.
2. **Run** the code on your own machine.
3. **Modify** the example to test your understanding.
4. **Practice** by solving the exercises without copying the solution.
5. **Build** a small project that applies the concept to a DevOps task.
