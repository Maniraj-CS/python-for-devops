# Python Dictionaries, Sets, and File Operations

## 1. Dictionaries

### What is a Dictionary?

A dictionary is a Python data structure that stores data as **key-value pairs**.

Each key is used to access its corresponding value. Dictionaries are mutable, which means you can add, update, or remove items after creating them.

In other programming languages, similar data structures are often called hash maps or associative arrays.

```python
my_dict = {
    "name": "John",
    "age": 25,
    "city": "New York"
}

print(my_dict)
```

**Output:**
```text
{'name': 'John', 'age': 25, 'city': 'New York'}
```

### Accessing Values

Use the key inside square brackets `[]` to access its value.

```python
my_dict = {
    "name": "John",
    "age": 25,
    "city": "New York"
}

print(my_dict["name"])
# Output: John
```

You can also use `get()` to access a value safely when a key might not exist.

```python
print(my_dict.get("age"))
# Output: 25

print(my_dict.get("email", "Not found"))
# Output: Not found
```

**Difference:**

- `my_dict["email"]` raises a `KeyError` if the key does not exist.
- `my_dict.get("email")` returns `None` by default if the key does not exist.
- `my_dict.get("email", "Not found")` returns the specified default value.

### Modifying and Adding Elements

Assign a new value to an existing key to update it. Assign a value to a new key to add an item.

```python
my_dict = {
    "name": "John",
    "age": 25
}

my_dict["age"] = 26
my_dict["occupation"] = "Developer"

print(my_dict)
# Output: {'name': 'John', 'age': 26, 'occupation': 'Developer'}
```

**DevOps Example:**

```python
server = {
    "name": "web-01",
    "ip": "192.168.1.10",
    "status": "running"
}

server["status"] = "stopped"
server["port"] = 8080

print(server)
```

A dictionary can store related information about a server in one place.

### Removing Elements

Use `del` to remove a key-value pair.

```python
my_dict = {
    "name": "John",
    "age": 25,
    "city": "New York"
}

del my_dict["city"]

print(my_dict)
# Output: {'name': 'John', 'age': 25}
```

You can also use `pop()` to remove a key and return its value.

```python
age = my_dict.pop("age")

print(age)       # Output: 25
print(my_dict)   # Output: {'name': 'John'}
```

### Checking Key Existence

Use the `in` operator to check whether a key exists.

```python
my_dict = {
    "name": "John",
    "age": 25
}

if "age" in my_dict:
    print("Age is present in the dictionary")
```

**Output:**
```text
Age is present in the dictionary
```

**Important:** By default, `in` checks dictionary keys, not values.

### Iterating Through Keys and Values

Use `.items()` to iterate through key-value pairs.

```python
my_dict = {
    "name": "John",
    "age": 25,
    "city": "New York"
}

for key, value in my_dict.items():
    print(key, value)
```

**Output:**
```text
name John
age 25
city New York
```

Other useful methods:

```python
print(my_dict.keys())    # All keys
print(my_dict.values())  # All values
print(my_dict.items())   # Key-value pairs
```

### DevOps Example: Server Monitoring Data

```python
servers = {
    "web-01": "running",
    "web-02": "stopped",
    "db-01": "running"
}

for server, status in servers.items():
    print(f"{server}: {status}")
```

**Output:**
```text
web-01: running
web-02: stopped
db-01: running
```

This demonstrates how dictionaries can organize server status information. The values are predefined; the script does not actually monitor the servers.

## 2. Sets and Set Operations

### What is a Set?

A set is a collection of **unique elements**. Sets are mutable, but they do not support indexing like lists.

Sets are useful for removing duplicates, checking membership, and performing mathematical set operations.

```python
my_set = {1, 2, 3, 4, 5}

print(my_set)
```

The set contains the numbers `1`, `2`, `3`, `4`, and `5`. Sets are unordered, so you should not depend on a particular display order.

**Important:** To create an empty set, use `set()`, not `{}`. Empty curly braces create an empty dictionary.

### Adding and Removing Elements

Use `add()` to add an element and `remove()` to remove one.

```python
my_set = {1, 2, 3, 4, 5}

my_set.add(6)
my_set.remove(3)

print(my_set)
# Contains: {1, 2, 4, 5, 6}
```

`remove()` raises a `KeyError` if the element does not exist. Use `discard()` if you want to remove an element without raising an error when it is missing.

```python
my_set.discard(10)  # No error if 10 is absent
```

### Set Operations

Suppose two teams are working on different server groups.

```python
team_a = {"web-01", "web-02", "db-01"}
team_b = {"web-02", "web-03", "db-02"}
```

#### Union

Union combines all unique elements from both sets.

```python
union_set = team_a.union(team_b)

print(union_set)
```

Result contains:

```text
web-01, web-02, db-01, web-03, db-02
```

The actual display order is not guaranteed.

You can also use the `|` operator:

```python
union_set = team_a | team_b
```

#### Intersection

Intersection returns elements that exist in both sets.

```python
intersection_set = team_a.intersection(team_b)

print(intersection_set)
# Contains: {'web-02'}
```

You can also use `&`:

```python
intersection_set = team_a & team_b
```

#### Difference

Difference returns elements that exist in the first set but not in the second.

```python
difference_set = team_a.difference(team_b)

print(difference_set)
# Contains: {'web-01', 'db-01'}
```

You can also use `-`:

```python
difference_set = team_a - team_b
```

**DevOps use:** These operations can help compare server inventories across environments, teams, or deployment configurations.

### Subset and Superset

A **subset** contains only elements that are also present in another set.

A **superset** contains every element of another set.

```python
set1 = {2, 3}
set2 = {1, 2, 3, 4}

is_subset = set1.issubset(set2)
is_superset = set2.issuperset(set1)

print(is_subset)    # Output: True
print(is_superset)  # Output: True
```

- `issubset()` checks whether every element of the first set exists in the second.
- `issuperset()` checks whether the first set contains every element of the second.

**DevOps Example:**

```python
required_ports = {22, 80, 443}
configured_ports = {22, 80, 443, 8080}

print(required_ports.issubset(configured_ports))
# Output: True
```

This checks whether all required port numbers appear in the configured collection. It does not verify actual firewall settings or network access.

## 3. Lists vs. Sets

Lists and sets both store multiple values, but they behave differently.

### Lists

#### Ordered Collection

Lists preserve their element order and support indexing.

```python
my_list = [1, 2, 3, 4, 5]

print(my_list[0])
# Output: 1
```

#### Mutable

You can modify list elements after creation.

```python
my_list = [1, 2, 3]

my_list[1] = 10

print(my_list)
# Output: [1, 10, 3]
```

#### Allows Duplicate Elements

```python
my_list = [1, 2, 2, 3, 4]

print(my_list)
# Output: [1, 2, 2, 3, 4]
```

#### DevOps Use Case

Use a list when you need to preserve order, allow duplicates, or access elements by position.

```python
deployment_targets = ["web-01", "web-02", "web-01"]

print(deployment_targets[0])
# Output: web-01
```

The repeated server name remains in the list.

### Sets

#### Unordered Collection

Sets do not support indexing.

```python
my_set = {1, 2, 3, 4, 5}

# my_set[0]  # Raises TypeError
```

#### Mutable

You can add or remove elements after creating a set.

```python
my_set = {1, 2, 3}

my_set.add(6)

print(my_set)
# Contains: {1, 2, 3, 6}
```

#### No Duplicate Elements

```python
my_set = {1, 2, 2, 3, 4}

print(my_set)
# Contains: {1, 2, 3, 4}
```

Duplicate values are automatically removed.

#### DevOps Use Case

Use a set when you need unique values, such as a collection of server names without duplicates.

```python
deployment_targets = {"web-01", "web-02", "web-01"}

print(len(deployment_targets))
# Output: 2
```

### Common Operations

| Operation | List | Set |
|---|---|---|
| Add an element | `append()` | `add()` |
| Insert at a position | `insert()` | Not supported |
| Remove an element | `remove()` | `remove()` or `discard()` |
| Access by index | Yes | No |
| Allow duplicates | Yes | No |
| Check membership | `in` | `in` |
| Union/intersection | Not directly supported as set operations | Supported |

Membership checks using `in` are generally faster on sets than on lists for large collections, on average. Actual performance depends on the data and operation.

### Choosing Between Lists and Sets

**Use lists when:**
- You need to preserve the order of elements.
- Duplicate elements are allowed.
- You need to access elements by index.

**Use sets when:**
- You need unique elements.
- Element order and indexing are not important.
- You need union, intersection, or difference operations.
- You frequently check whether an element exists.

## 4. Project — Fetch Pull Request Creators from GitHub

### Project Overview

This project uses the GitHub REST API to retrieve open pull requests from the Kubernetes GitHub repository and count how many pull requests each user created in the returned results.

It demonstrates:
- Making HTTP requests using `requests`.
- Reading JSON data from an API.
- Working with dictionaries.
- Iterating through a list of API results.
- Counting occurrences using dictionary values.
- Handling HTTP errors.

### Install the Required Library

```bash
python3 -m pip install requests
```

### Complete Code

```python
import requests

# GitHub API endpoint for open pull requests
url = "https://api.github.com/repos/kubernetes/kubernetes/pulls"

try:
    response = requests.get(
        url,
        params={"state": "open", "per_page": 100},
        timeout=15
    )

    if response.status_code == 200:
        pull_requests = response.json()

        # Store each creator and their pull request count
        pr_creators = {}

        for pull in pull_requests:
            creator = pull["user"]["login"]

            if creator in pr_creators:
                pr_creators[creator] += 1
            else:
                pr_creators[creator] = 1

        print("Open PR Creators and Counts:")

        for creator, count in pr_creators.items():
            print(f"{creator}: {count} PR(s)")

    else:
        print(
            f"Failed to fetch data. "
            f"Status code: {response.status_code}"
        )

except requests.RequestException as error:
    print(f"Request failed: {error}")
```

### Understanding the Code

#### Step 1: Set the API URL

```python
url = "https://api.github.com/repos/kubernetes/kubernetes/pulls"
```

This endpoint provides pull request information for the Kubernetes repository.

The example requests open pull requests and up to 100 results per page. It does not automatically fetch every page, so the counts apply only to the results returned.

#### Step 2: Send a GET Request

```python
response = requests.get(
    url,
    params={"state": "open", "per_page": 100},
    timeout=15
)
```

- `requests.get()` sends an HTTP GET request.
- `params` adds query parameters to the URL.
- `timeout=15` limits how long the program waits for the request.

#### Step 3: Check the Response

```python
if response.status_code == 200:
    pull_requests = response.json()
```

HTTP status code `200` means the request succeeded.

The `.json()` method converts the JSON response into Python objects. In this API response, the pull requests are represented as a list of dictionaries.

#### Step 4: Count Pull Request Creators

```python
pr_creators = {}

for pull in pull_requests:
    creator = pull["user"]["login"]

    if creator in pr_creators:
        pr_creators[creator] += 1
    else:
        pr_creators[creator] = 1
```

Suppose two pull requests were created by the same user, `alex`.

The dictionary might look like this:

```python
pr_creators = {
    "alex": 2,
    "sam": 1
}
```

The program:
1. Reads the creator's login from each pull request.
2. Checks whether that creator is already a dictionary key.
3. Increases the count if the key exists.
4. Creates the key with a count of `1` otherwise.

This pattern is called **frequency counting**.

A shorter alternative is:

```python
pr_creators[creator] = pr_creators.get(creator, 0) + 1
```

This retrieves the existing count, or `0` if the creator is new, then adds one.

#### Step 5: Display the Results

```python
for creator, count in pr_creators.items():
    print(f"{creator}: {count} PR(s)")
```

The `.items()` method gives each dictionary key and value, allowing the program to print each creator and their count.

### Important Notes

- The GitHub API can return changing results as pull requests are opened or closed.
- This example counts only the open pull requests returned by the first page.
- Public repository data can generally be accessed without authentication, but unauthenticated requests have lower rate limits.
- If you want to analyze all open pull requests, you must handle pagination.

## 5. File Operations

File operations allow Python programs to create, read, write, and update files.

These operations are useful in DevOps for working with application configuration, logs, reports, and automation output.

### Opening a File

Use `open()` to open a file.

```python
file = open("example.txt", "r")
```

The second argument specifies the mode.

| Mode | Purpose |
|---|---|
| `"r"` | Read an existing file |
| `"w"` | Write to a file; overwrite existing content or create the file |
| `"a"` | Append content to the end of a file or create it |
| `"x"` | Create a new file; fail if it already exists |
| `"rb"` | Read a file in binary mode |
| `"wb"` | Write a file in binary mode |

### Reading a File

```python
with open("example.txt", "r") as file:
    content = file.read()

print(content)
```

- `with` manages the file resource and closes it when the block ends.
- `read()` reads the file's content.

### Reading Lines

```python
with open("example.txt", "r") as file:
    lines = file.readlines()

for line in lines:
    print(line.strip())
```

`readlines()` returns a list of lines. `strip()` removes surrounding whitespace, including the newline at the end.

### Writing to a File

```python
with open("example.txt", "w") as file:
    file.write("Application started\n")
    file.write("Application running\n")
```

**Important:** `"w"` overwrites the existing file content. Use `"a"` if you want to append instead.

### Appending to a File

```python
with open("example.txt", "a") as file:
    file.write("New log entry\n")
```

This adds the new entry to the end of the file.

### Checking Whether a File Exists

```python
import os

if os.path.exists("example.txt"):
    print("File or path exists")
else:
    print("Path does not exist")
```

`os.path.exists()` checks whether the path exists. It does not guarantee that the path is a file or that the program has permission to read it.

**DevOps use:** File operations are a foundation for scripts that read configuration, process logs, and generate deployment reports.

## 6. Project — Update a Server Configuration File

### Project Overview

This project updates a configuration value in a file named `server.conf`.

For example, you may need to change `MAX_CONNECTIONS` from `600` to another value.

The program reads the existing file, finds the exact configuration key, updates its value, and preserves the other lines.

### Example `server.conf`

```text
# Server Configuration File

# Network Settings
PORT = 8080
MAX_CONNECTIONS=600
TIMEOUT = 30

# Security Settings
SSL_ENABLED = true
SSL_CERT = /path/to/certificate.pem

# Logging Settings
LOG_LEVEL = INFO
LOG_FILE = /var/log/server.log

# Other Settings
ENABLE_FEATURE_X = true
```

### Complete Code

```python
def update_server_config(file_path, key, value):
    with open(file_path, "r") as file:
        lines = file.readlines()

    updated = False

    with open(file_path, "w") as file:
        for line in lines:
            stripped_line = line.strip()

            # Ignore comments and lines without "="
            if stripped_line.startswith("#") or "=" not in stripped_line:
                file.write(line)
                continue

            # Split only at the first "="
            config_key, _ = stripped_line.split("=", 1)

            if config_key.strip() == key:
                file.write(f"{key} = {value}\n")
                updated = True
            else:
                file.write(line)

    if not updated:
        raise KeyError(f"Configuration key not found: {key}")


server_config_file = "server.conf"

key_to_update = "MAX_CONNECTIONS"
new_value = "800"

update_server_config(
    server_config_file,
    key_to_update,
    new_value
)

print(f"{key_to_update} updated successfully")
```

### Understanding the Code

#### Step 1: Read the Existing File

```python
with open(file_path, "r") as file:
    lines = file.readlines()
```

The program reads every line and stores the lines in a list.

#### Step 2: Track Whether the Key Was Found

```python
updated = False
```

This Boolean variable records whether the requested key has been found and updated.

#### Step 3: Open the File for Writing

```python
with open(file_path, "w") as file:
```

The program writes the original lines back, replacing the target configuration line.

**Important:** Opening a file with `"w"` truncates it immediately. If writing fails partway through, the file may be left incomplete. For production configuration management, use a temporary file and replace the original only after a successful write, and consider making a backup.

#### Step 4: Ignore Comments and Non-Configuration Lines

```python
stripped_line = line.strip()

if stripped_line.startswith("#") or "=" not in stripped_line:
    file.write(line)
    continue
```

This prevents comments such as `# Network Settings` from being mistaken for configuration entries.

#### Step 5: Match the Exact Key

```python
config_key, _ = stripped_line.split("=", 1)

if config_key.strip() == key:
    file.write(f"{key} = {value}\n")
    updated = True
else:
    file.write(line)
```

The line is split at the first `=`. The left side is compared with the requested key after removing surrounding whitespace.

This is safer than using `if key in line`, which can match unrelated text.

#### Step 6: Report a Missing Key

```python
if not updated:
    raise KeyError(f"Configuration key not found: {key}")
```

If no matching key was found, the program raises an error instead of silently pretending that the update succeeded.

### Expected Result

With `new_value = "800"`, the updated configuration line becomes:

```text
MAX_CONNECTIONS = 800
```

The other lines are written back unchanged.

### Important DevOps Note

This project demonstrates basic configuration-file editing. Real production configuration updates should also consider file permissions, backups, validation, atomic replacement, and whether the application needs to reload or restart to apply the change.

## 7. Quick Summary

| Topic | Main Use |
|---|---|
| Dictionary | Store and retrieve key-value pairs |
| `get()` | Access a value with a default |
